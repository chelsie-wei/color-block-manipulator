# SpellBot
An interactive robot robotic system that rearranges colored letter blocks to spell user-defined words. This is the final project for CS150 Intro to ROS, Spring 2026, taught by Dr. Elaine Short.  
<img src="https://a.storyblok.com/f/169662/1125x1500/d81c866521/png-ur3e_01_r.png/m/fit-in/1072x1364" width="150">

## Description  
The current project programs a robotic arm (specifically, the UR3e) to pick up a target letter block and place it in the order requested by the user. The system is interactive through its closed-loop sensing mechanism: the user places a letter block on a platform, the robot arm detects the block’s position using a camera, and then autonomously picks up and rearranges the block accordingly. The final form of the project includes an interactive page where users can instruct the specific word to rearrange into. Please see TODOs below for more.
